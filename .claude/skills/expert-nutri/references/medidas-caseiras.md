# Medidas Caseiras → Gramas

Conversões aproximadas usadas para traduzir grama em algo que uma pessoa
comum consiga servir sem balança. Ajuste ±10-15% conforme a densidade real
do alimento específico — estes são valores de referência, não exatos.

## Colheres
| Medida | Alimento seco/farináceo | Alimento líquido/pastoso |
|---|---|---|
| Colher de chá | ~5g (chia, farinha) | ~5ml |
| Colher de sobremesa | ~8g | ~10ml |
| Colher de sopa (rasa) | ~15g (arroz, tapioca, cuscuz) | ~15ml (azeite, doce de leite) |
| Colher de sopa (cheia) | ~20-25g | ~20ml |

## Outras medidas
| Medida | Equivalência típica |
|---|---|
| Concha (feijão/caldo) | ~70-80g |
| Escumadeira cheia (arroz cozido) | ~90g (convenção interna da Curva, não padronizada; confirme a porção real; ½ = ~45g) |
| Xícara de chá | ~200ml (líquido) / ~120g (arroz cru) |
| Pote de iogurte individual | ~170-200g |
| Fatia (melancia/melão/mamão/abacaxi) | ~100-150g, varia muito — especificar peso junto |
| Prato de salada crua | ~120-150g |
| Pedaço (queijo, mandioca, doce de leite) | ~20-30g — sempre dar o peso junto, "pedaço" sozinho é ambíguo |
| Unidade pequena de fruta (banana, kiwi, maçã) | ~60-75g |
| Unidade média de fruta (manga, pera) | ~80-100g |
| Filé/bife/peito (proteína, porção principal) | ~100-150g — "1 unidade" só funciona se o corte for padronizado (ex: filé de peito inteiro), senão especificar gramas |

## Regras de uso

- Sempre grama entre parênteses, medida caseira como texto principal:
  `"Arroz branco – 3 colheres de sopa (70g)"`, nunca só `"70g de arroz"`.
- Quando a quantidade ajustada cair numa fração estranha (ex: 27g),
  arredonde pra medida caseira mais próxima plausível ("3 colheres de sopa
  rasas") — a grama exata fica só na tabela-resumo de registro interno.
- Frações de unidade (½ prato, 1½ pedaço, ¾ de xícara) são aceitáveis e
  mais fáceis de visualizar do que gramas soltos — prefira isso a inventar
  uma medida nova.
